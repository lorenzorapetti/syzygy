# Strip sone's proxy support instead of porting it disabled

Proxy support is out of syzygy's prototype scope, but in sone it is threaded through the engine: `TidalClient` is built on `proxy_http::ProxiedHttp`, `AudioPlayer` routes GStreamer sources through `proxy::Route`, and `tidal_report` uses the proxied client. We strip it rather than port `proxy`/`proxy_http` (about 3.4k lines, about 130 tests) and run them with disabled settings. Every one of those tests covers behaviour syzygy doesn't ship, and carrying the plumbing would shape every engine interface around a feature nobody uses. `TidalClient` takes a plain `reqwest::Client`, `AudioProxy` and its route plumbing leave the audio crate, and `ProxyBlocked`/`explain_block` go away. If proxy support is wanted later, sone at `0488f97` is the reference to port it from.
