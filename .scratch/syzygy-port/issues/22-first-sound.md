# 22: First sound: audio engine, pure playback update and player bar

**What to build:** clicking a track on an Album Page plays it bit-perfect, from that track to the end of the album, never wrapped around. The player bar shows what's playing, with play/pause, a seek bar that commits on release, volume and mute. This is the first slice through ADR 0002, ADR 0003 and ADR 0004, and the start of test Seam 1. See user stories 66, 88, 92, 94–95 and the spec's "Playback model" and "Bridge between engines and iced".

**Blocked by:** 17

**Status:** ready-for-agent

- [x] `syzygy-audio`: sone's `AudioPlayer` (GStreamer and DirectAlsa) without proxy, `SignalPathTracker` without emits, `pipeline_probe` parsers (its 24 tests pass), `compute_norm_gain`, `PositionCell`, a typed `Event` enum. `GST_PLUGIN_PATH` selection lives in the binary
- [x] The audio API is async (replies over `oneshot`), run as `Task::perform`. Engine events come through a boot-created `run_with` subscription mapped to `Message::Audio`
- [x] `playback::update` is pure: it changes state and returns `Vec<Effect>`. A thin runner turns effects into `Task`s against `Services` (ADR 0002)
- [x] Every start goes through `PlayRequest { source, first_page, continuation }`. The Playback source owns its tracks in source order, and playback keeps a play order and a cursor (ADR 0004)
- [x] Each `Play` carries a `PlayToken` echoed by its result, and stale results are dropped. The current track changes optimistically and rolls back on failure
- [x] Status is `Stopped | Loading(token) | Playing | Paused`. A 250 ms tick runs only while playing and reads `PositionCell`. Track end comes only from `TrackFinished`
- [x] The 90px player bar (30/40/30): cover, title, artist, play/pause, a seek bar that commits on release, volume and mute (restores the pre-mute volume, 0.5 if none). Volume and mute are playback state
- [x] Seam 1 tests cover starting a source with no wrap-around, and dropping stale play tokens

## Comments

Implemented. Notes for later tickets:

- **`syzygy-audio`.** sone's `audio.rs`, `signal_path.rs` and `pipeline_probe.rs`, ported by a scripted transform so nothing changed by hand in the engine bodies. Gone: the proxy (`AudioProxy`, route generations, `SetProxySettings` and the mid-track rebuild), `GetPosition`, `IsFinished` and the `eos`/`has_uri`/`current_uri` state that only those used. `AudioPlayer::new(UnboundedSender<Event>)` owns its `SignalPathTracker` (`signal_path()` gives a snapshot; nothing is emitted). Every call sends its command **at call time** and returns a `'static` future for the oneshot reply, so commands reach the audio thread in the order they're made. `Event`: `TrackFinished`, `TrackAdvanced { track_id, entry, replay_gain, peak_amplitude }` (sone's `qid` is now an opaque `entry: u64`), `Failed { kind: ErrorKind, message }`, `Resampled`, `BitDepthChanged`. `Error`: `DeviceBusy`, `Engine(String)`, `Gone` (GStreamer failed to init, or the thread died). `PositionCell` is an `ArcSwapOption` of the pipeline or the ALSA frame counters, swapped in on each `PlayUrl` and cleared on `Stop`. `compute_norm_gain` is in the crate root. Deps bumped: gstreamer 0.25, alsa 0.12.
- **Binary.** `plugin_path::select()` runs first in `main` (sone's rules, plus: leave `GST_PLUGIN_PATH` alone when `GST_PLUGIN_SYSTEM_PATH(_1_0)` is set, so a Nix GStreamer never loads the host's `/usr/lib` plugins). `Services` gains `player` and `position`. The audio `EventSource` is always subscribed, in Login too. `Message::Tick` (every 250 ms only while `Status::Playing`) reads `PositionCell` in the App and sends `playback::Message::Position`. Boot pushes only the saved volume to the engine: exclusive mode, bit-perfect and gapless wait for ticket 31's linkage. The volume is saved to `Settings` on slider release and on mute.
- **`playback`.** `Playback::update(Message) -> Vec<Effect>`. Effects so far: `Play { token, track_id, from }`, `Pause`, `Resume`, `Seek`, `SetVolume`. The source and its place are `SourcePlay { source: SourceRef, tracks: Arc<Vec<Track>>, order, cursor }` (named so it isn't read as the Manual queue). `PlayRequest { source, first_page, start }`: **no `continuation` yet**, since no paged source starts in this ticket; ticket 24 adds it with `StartFill`. Rollback: each play snapshots what played before it (once per run of loads). A **resolve** failure puts it back as it was, and an **engine** failure puts it back Stopped (the engine let go of the old track). If the old track ends or breaks while the new one loads, the snapshot becomes Stopped. The runner (`App::run_playback`) resolves the stream (`max_quality`, track gain when `volume_normalization` is on), then `play_url`. It keeps the play task's abort handle and replaces it on each `Play`, so an older choice can't reach the engine after a newer one. Tokens drop its result. `EngineFailed` (any `audio::Event::Failed`) stops a playing track and keeps the position, so Play resumes there. Toasts for audio errors are ticket 26.
- **UI.** `Action::Play(PlayRequest)`; `track_list::playable(row, msg)` makes a row a button (inner links still win). Album rows play from their track, and each track gets the album as its `AlbumRef` if TIDAL left it out (the bar's cover). `shell::player_bar`: 90px, 3/4/3 portions, cover 64, semibold title, artists as links, the play disc, a seek slider that only seeks on release, the time either side, mute and a 100px volume slider. Icons added: play, pause, volume-1/2/x.
- **Dev env.** devenv.nix adds GStreamer (base/good/bad/libav) on `GST_PLUGIN_SYSTEM_PATH_1_0`, the gstreamer and base `.dev` outputs for pkg-config, and **glib-networking on `GIO_EXTRA_MODULES`**. Without it every HTTPS stream fails with "Internal data stream error … souphttpsrc … reason error (-5)".
- **Tested:** 23 Seam 1 tests (no wrap-around, finishing through to Stopped, stale results and stale failures dropped, rollback after resolve and engine failures and after rapid choices, the old track ending or breaking during a load, Play from the stored position, seek, volume, mute) and sone's 24 `pipeline_probe` tests, plus 11 for the plugin path. That's 309 in the workspace. **Run:** against TIDAL with the stored Session, through a temporary patch that searched "daft punk discovery" and started the album at track 13 of 14. It played (16-bit/44.1 FLAC over DASH), the tick advanced the position, Seek(30) landed at 28 s (key unit), pause and resume kept the place, mute went 0 and back to 1, and seeking past the end gave `TrackFinished`, then track 14. A screenshot showed the player bar drawing as intended. I didn't click through the window by hand.
